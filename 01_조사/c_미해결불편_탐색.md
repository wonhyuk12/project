# (c) 일상 속 미해결 불편 — AI가 아니면 못 푸는 것 [혼합: 통계는 출처명시, 판단은 추정]

목적: 단순 자동화(알림, 리마인더, 분류)로 되는 건 창의성 점수가 안 나온다. "AI가 아니면 못 푸는 것"의 기준을 아래처럼 잡는다:
- 서로 다른 출처의 비정형 정보를 종합해 **판단**을 내려야 함 (예: 여러 처방전의 약물 상호작용, 낯선 키오스크 화면의 실시간 이해)
- **개인마다 다른 맥락**에 맞춰 매번 다시 생성해야 함 (정적 매뉴얼로 대체 불가)
- 텍스트·이미지·음성 등 **비정형 입력의 실시간 해석**이 필요함

## 조사로 확인한 미해결 불편 (통계 근거 있는 것 위주)

1. **고령자 다약제 복용·상호작용 위험** — 복합만성질환자는 복약불순응 높음, 고혈압 목표혈압 조절률 50.4%에 불과 (인지율71.2%·치료율66.9%인데도). 자녀 없는 1인가구가 복약순응 가장 낮음.
   출처: [65세 이상 만성질환자의 가구형태와 복약순응도](https://www.kci.go.kr/kciportal/ci/sereArticleSearch/ciSereArtiView.kci?sereArticleSearchBean.artiId=ART003065162)
   → 단순 "복약 알림 앱"은 이미 많음(자동화 영역). AI가 필요한 지점은 **여러 병원 처방을 종합한 중복성분/상호작용 판단 + 쉬운 말 설명**.

2. **키오스크 표준화 부재로 인한 취약계층 이용 곤란** — 키오스크 정보접근성 66.7~67.3점으로 3년째 정체. 휠체어 작동부 높이 준수율 4%, 음성 대체콘텐츠 제공 10.5%. 소비자 84.8%가 "기능 표준화 필요"에 응답.
   출처: [키오스크(무인정보단말기) 이용 실태조사](https://www.kca.go.kr/smartconsumer/sub.do?menukey=7301&mode=view&no=1003409523)
   → 표준화가 안 되는 한 정적 매뉴얼로는 대응 불가. **실시간 화면 이해(비정형)**가 필수라 AI가 아니면 못 푸는 문제에 해당 [추정].

3. **1인가구 식생활 건강 악화** — 1인가구 33.4% 식생활 건강 "빨간불"(나트륨 과다, 불규칙 식사, 영양 불균형).
   출처: [1인가구 33.4%, 식생활 건강 '빨간불'](https://www.ohmynews.com/NWS_Web/View/at_pg.aspx?CNTN_CD=A0002888622)
   → 다만 "AI 식단추천"은 공고문이 명시적으로 피하라고 한 뻔한 예시와 정면충돌. 소재로 쓰려면 차별화 각도가 강해야 함.

4. **다문화가정/외국인 근로자 언어·행정 장벽** — 다문화가구 약 105만(전체 2.1%), 결혼이민자는 의사소통·법률정보 부족으로 불리한 입장.
   출처: [다문화가족 지원 개요](https://www.easylaw.go.kr/CSP/CnpClsMain.laf?csmSeq=638&ccfNo=1&cciNo=1&cnpClsNo=2)
   → 구체 수치(문서 오독으로 인한 피해 빈도 등)는 [확인 못 함]. 단순 번역(파파고)로 안 풀리는 지점은 "이 조항이 나에게 불리한가"라는 **위험 판단**.

5. **고령층 대상 AI 활용 신종 사기(보이스피싱 외 확장)** — 60대 피해 비중 30.6%(전연령 1위), 10년간 5배 급증, 기관사칭 4배 증가.
   → 단, 이 영역은 (a)에서 확인했듯 이미 통신사·지자체·금융권이 정면 대응 중이라 신규성 방어가 어려움. **후보에서 제외 또는 differentiation 필요**.

6. **발달장애/특수교육 아동 돌봄 정보 비대칭** — 구체 수치는 [확인 못 함] (2단계에서 보건복지부 발달장애인 실태조사, 특수교육통계연보 추가 확인 필요). 정성적으로 부모의 행동패턴 기록·치료기관 공유 자료 작성 부담이 크다는 것은 [통설].

## 결론
확실한 통계 근거로 "AI가 아니면 못 푸는" 조건을 만족하는 후보는 **① 다약제 복용 상호작용 판단, ② 키오스크 실시간 대리조작**이 가장 강하다. ③ 다문화가정 문서 리스크 설명은 근거는 있으나 "매일" 빈도가 약하다. ④ 식생활/식단은 소재 자체가 공고문이 경고한 뻔한 예시에 가까워 보류.
